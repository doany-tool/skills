# Business tool skills

Install a skill to work through a business task in your agent. Each skill includes an example and links to the corresponding browser tool.

## Preview locally

From this repository, list the available skills or install one by its identifier.

```sh
npx skills add . --list
npx skills add . --skill service-pricing-calculator
```
