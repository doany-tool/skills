# Product description generator

Use the [Product description generator](https://doany.ai/tools/product-description-generator?utm_source=skills.sh&utm_medium=skill&utm_campaign=product-description-generator&utm_content=product-description-generator) to edit or copy a listing after checking what buyers receive and how delivery works.

## Collect the buying facts

Get product name, type, intended buyer, included items, a clear benefit, and delivery or access details. Ask about compatibility, size, file format, prerequisites, and exclusions when relevant. Confirm a price and currency only if the user wants them in the listing.

## Write and check the copy

1. Lead with what the product is and who it helps. Explain what buyers receive in concrete terms. For a digital product, clarify file type, access and requirements. For a physical product, cover size or contents and verified fulfillment details. For a service, state deliverables and boundaries.
2. If the user wants variants, use distinct openings such as benefit-led, detail-led, and quick summary. For a full-and-short set, keep the same facts and retain the most important purchase condition in both.
3. Check every material, feature, claim, guarantee, price, and delivery statement against the user's facts. Return the copy in labeled, paste-ready blocks.

## Browser workflow

When the page exposes browser actions, use `write_product_description` with the confirmed product facts, then `get_product_description` to check the current copy before handing it over.

## Example

For a downloadable planner, specify whether it is a printable PDF, a fillable PDF, or both. State the page count and software requirement only when known, and describe the planning task it helps the buyer finish.
