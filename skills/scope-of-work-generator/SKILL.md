# Scope of work generator

Use the [Scope of work generator](https://doany.ai/tools/scope-of-work-generator?utm_source=skills.sh&utm_medium=skill&utm_campaign=scope-of-work-generator&utm_content=scope-of-work-generator) to turn the agreed scope into an editable document and export a PDF.

## Gather the agreement

Ask for the customer goal, project location or reference, deliverables, quantities, included areas, and any timing commitments. Ask who supplies access, equipment, source files, or approvals. Get explicit exclusions and who decides whether the work is accepted.

## Write the scope

1. Name the deliverables with counts, dimensions, file formats, or the boundaries of the work. Give each major deliverable its own line.
2. Record the customer's responsibilities and prerequisites. Separate a confirmed schedule from dependencies that can shift it.
3. Write observable completion checks for each deliverable and specify how the owner will review them. Capture what happens when scope changes using the user's actual process.
4. Keep the document focused on work and acceptance. Use the preview to check the latest wording and export the final scope when approved.

## Browser workflow

When the page exposes browser actions, use `create_scope_of_work` with the agreed sections and `get_scope_of_work` to read back the document. Verify measurable acceptance conditions before exporting.

## Example

For a website refresh, specify five named pages, editable copy, and mobile review. State who supplies images and what counts as approval. List ongoing maintenance separately if it is outside the work.
