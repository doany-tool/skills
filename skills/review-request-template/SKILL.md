# Review request template

Use the [Review request template](https://doany.ai/tools/review-request-template?utm_source=skills.sh&utm_medium=skill&utm_campaign=review-request-template&utm_content=review-request-template) to personalize the request and copy it into the owner's messaging channel.

## Get the relevant details

Confirm the customer name or placeholder, completed service, business and location, and direct review URL. If the link is missing, use a clear placeholder and ask the owner for the verified location link. Ask whether the customer has already reviewed before drafting a reminder.

## Write the selected version

1. For SMS, use a short thank-you, the request, and the link. For email, add a short subject and enough service context to identify the visit.
2. For a gentle follow-up, acknowledge the earlier request once and make the message easy to ignore. Keep the same link and neutral wording.
3. Invite honest feedback from customers consistently. Keep incentives, requested ratings, and prompts to say particular things out of the message.
4. Return the copy for owner review. Confirm the link points to the intended listing before sharing.

## Browser workflow

When the page exposes browser actions, use `write_review_request` with the requested channel and verified link, then `get_review_request` to review the copy.

## Example

After a gutter cleaning visit, thank the customer for booking and ask whether they would like to share their experience. Use the verified Google review link for the branch that did the work.
